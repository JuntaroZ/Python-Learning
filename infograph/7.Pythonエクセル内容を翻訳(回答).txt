・以下内容を初心者もわかるようインフォグラフィックスを作成
・タイトル：Python でエクセル内容を翻訳してみよう！
・A1に「日本語」、B1に「英語」が入っています
・A2, B2以降は以下内容にしてください。
　・おはようございます。	Good morning.
　・今日はとてもいい天気です。	It is very nice weather today.
　・私は毎朝コーヒーを飲みます。	I drink coffee every morning.
・A4サイズで作成すること
・文字化けを修正してください

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
import openpyxl
from google import genai

# エクセルを読み込む
book = openpyxl.load_workbook("./excel/translate.xlsx")
sheet = book.active

SOURCE_LANG = sheet["A1"].value # 翻訳元言語をシートA1から取得
TARGET_LANG = sheet["B1"].value # 翻訳先言語をシートB1から取得

print("翻訳元言語：" + SOURCE_LANG  + "、翻訳先言語：" + TARGET_LANG)

client = genai.Client()
chat = client.chats.create(model="gemini-3.5-flash-lite")

index = 2 # A2から開始
while True: # 無限ループ
    # A列の文章を読み取る
    translate_text = sheet[f"A{index}"].value
    # A列が空白の場合はループを抜ける
    if translate_text is None or translate_text == "":
        break
    # 翻訳を実行する
    response = chat.send_message(
        SOURCE_LANG + "を" + TARGET_LANG + "に翻訳（翻訳結果を１つ返してください）：" + translate_text
    )
    # B列の各行に結果(response.text)を書き込む
    sheet[f"B{index}"].value = response.text
    # 次の行に移動する
    index += 1
    
book.save("./excel/translate.xlsx")
